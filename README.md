### 🚀 Highlights & Changelog (v1.0.5)
- **IPOWiz.in Exclusive Single Source of Truth**: Full migration to `ipowiz.in` as the sole authoritative source for all IPO master records, lifecycle statuses, price bands, and lot sizes.
- **Accurate Issue Size Extraction**: Comprehensive deep-enrichment from IPOWiz Table 2 across all 250 master IPOs (e.g. Hero Motors ₹1,000 Cr, Powerica ₹1,100 Cr, GV Electricals ₹42.25 Cr, ICICI Prudential AMC ₹10,602.65 Cr).
- **Zero Fallback & Zero Legacy Stale Records**: Removed all secondary provider dependencies (IndianAPI, IPOAlerts, Upstox, IPODekho) from active IPO creation and status determination.
- **Active Reconciliation**: Database strictly mirrors live IPOWiz dataset 1-to-1 (250 / 250 records).
- **All 460 Automated Tests Passing** across Flutter, Supabase Deno Edge Functions, Admin Panel, and Web.
