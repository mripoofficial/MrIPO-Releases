### 🚀 Highlights & Changelog (v1.0.6)
- **Open IPO Card UI Standardization**: Standardized layout with inline `SME`/`Mainboard` badge next to the company name on line 1, and `Open` status badge directly next to bidding dates and issue day on line 2.
- **Single-Line GMP Metric**: Scaled metric formatting to guarantee GMP amount and percentage always display on a single line without wrapping.
- **Polished & Compact Subscription Table**: Attractive, space-saving table styling with rounded corners (6px), subtle border tinting, and compact padding.
- **IPOWiz Upcoming Synchronization**: Synced all upcoming and live IPOs from IPOWiz directly into the live catalog.
- **All Automated Tests Passing (306/306)**.
